# MedSighter - Accessible Health Assistant

MedSighter is an accessibility-focused application designed to help visually impaired individuals manage medicine safely.

## Features

- Check medicine expiry dates
- Verify medicine matches prescription
- Voice control support
- Text-to-speech guidance
- Camera scanning
- OCR-based medicine text recognition

## Technology

- React + Vite
- Tailwind CSS
- Tesseract.js OCR
- Web Speech API

## Run Locally

```bash
npm install
npm run dev
```

No API key required.
